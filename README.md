# NextRound AI 🚀

An AI-powered mock interview platform built with the MERN Stack that helps users prepare for technical and HR interviews through voice-based AI interactions, resume analysis, real-time performance evaluation, and personalized interview simulations.

---

# 🌟 Features

## 🤖 AI-Powered Interview Generation
- Smart AI-generated interview questions
- Dynamic follow-up questioning
- Role-based interview customization
- Adaptive difficulty based on experience level

---

## 🎙️ Voice-Based AI Interviews
- Real-time voice interview simulation
- Interactive AI conversations

- Smart voice response evaluation

# ⚙️ Environment Variables

## Client `.env`

```env
VITE_FIREBASE_APIKEY=your_firebase_api_key
VITE_RAZORPAY_KEY_ID=your_razorpay_key
```

---

## Server `.env`

```env
PORT=8000

MONGODB_URL=your_mongodb_connection_url

JWT_SECRET=your_jwt_secret

OPENROUTER_API_KEY=your_openrouter_api_key

RAZORPAY_KEY_ID=your_razorpay_key

RAZORPAY_KEY_SECRET=your_razorpay_secret
```

# 🔥 Firebase Setup

1. Create a Firebase Project
2. Enable Google Authentication
3. Copy Firebase API Key

# 💻 Local Installation

## Clone Repository

```bash
git clone https://github.com/Harshit-verse/NextRound.git
```

---

## Install Frontend Dependencies

```bash
cd client
npm install
```

---

## Install Backend Dependencies

```bash
cd server
npm install
```

---

# ▶️ Run Locally

## Start Backend Server

```bash
cd server
npm run dev
```

---

## Start Frontend

```bash
cd client
npm run dev
```

---

# 🌐 Local URLs

```bash
Frontend → http://localhost:5173

Backend → import.meta.env.VITE_API_URL
```
